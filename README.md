# 霓虹装甲 · NEON TANK ARENA

**在线游玩：** [https://tankl.zard.pro/](https://tankl.zard.pro/)

3D 坦克射击对战游戏 —— 支持单机闯关与**多人在线对战**，不加载任何外部资源。驾驶霓虹重装坦克，单机抵御一波强过一波的 AI 装甲集群，或与朋友同场联机混战 / 组队抗击 AI 波次。

- **渲染**：Three.js 第三人称视角，战场 / 坦克 / 特效 / 音效全部程序化生成
- **运行方式**：`npm start` 后访问 `http://localhost:3099`（联机需走服务器；单机模式也可直接打开 `public/index.html`）
- **联机架构**：Node 权威服务器（20Hz 模拟，物理 / 炮弹 / 命中全部服务器判定）+ WebSocket 快照同步 + 客户端预测与软校正
- **持久化**：单机最高分存 `localStorage`；联机历史排行榜存服务器 `data/leaderboard.json`

## 核心玩法

- 3D 渲染的战场与坦克，第三人称跟随相机
- AI 坦克巡逻、索敌、预判射击与掩体绕行
- 炮弹抛物线飞行、命中判定、爆炸特效与溅射伤害
- 玩家装甲血量、装填冷却、击毁得分
- **三种载具**：猎手 / 疾袭 / 重装，进场时选择；阵亡重生沿用当前载具
- **多波次进攻**：猎手 / 疾袭 / 重装三种敌军，随波次增强
- 击毁敌军有概率掉落维修包（+30 装甲），波次清空奖励得分与装甲

## 联机模式（v3 新增）

一个 URL，多个浏览器标签页 / 手机 / 电脑直接进入同一房间开打，最多 16 人：

- **联机混战（PvP）**：玩家坦克互相开火；阵亡 3 秒后重生（带 2.5 秒重生保护，开火即解除）；击杀 +100 分并回血，连杀 3 / 5 / 8 / 12 有全场播报
- **联机合作（PvE）**：全队共抗 AI 波次，波次进度共享，清波全队奖励；玩家间免伤
- **模式切换**：聊天输入 `/mode pvp` 或 `/mode pve` 随时切换，`/reset` 清零比分
- **战场补给点**：11 个固定点位轮转刷新 —— 🔧修理包(+40 装甲) / 🛡能量护盾(8s 减伤 60%) / ⚡过载引擎(8s 移速+40%) / 🔥穿甲弹(10s 伤害×1.5)，吃后 15 秒重生
- **其他玩家**：独立配色坦克 + 头顶昵称血条名牌，重生保护期闪烁提示
- **聊天**：回车输入，Esc 关闭；**排行榜**：按住 Tab 实时查看击杀榜
- **雷达**：金色三角标记其他玩家方位
- **断线重连**：连接中断自动重连并恢复战斗
- 历史排行榜（按昵称累计击杀 / 阵亡 / 最高连杀 / 得分）可通过 `/api/leaderboard` 查询

## 界面与设置

- **开始界面**：单机闯关 / 联机混战、昵称输入（联机）、历史最高分、音乐 / 音效开关
- **进场选车**：点「进入战斗」或「闯关」后选择猎手 / 疾袭 / 重装，点选后立即进入；阵亡重生沿用当前载具，返回大厅或重新进入后才能换车
- **战斗 HUD**：装甲条、波次与残敌（联机为在线人数 / 残敌）、得分、雷达、装填条、击杀提示、联机状态徽章（模式 / 人数 / 增益）
- **暂停 / 结算**：继续、重开、返回主菜单；结算展示本局数据与新纪录（单机）
- **音效开关**：背景音乐与音效独立控制，设置持久保存

## 适配说明

- **逻辑分辨率固定**：横屏 1280×720、竖屏 720×1280，按屏幕等比缩放居中
- **窄屏自动适配**：竖屏时 HUD 布局自动调整
- **画质自适应**：帧率持续偏低时自动降低阴影 / 粒子密度（视距不变）
- **零外部资源**：模型、贴图、音效、BGM 均为运行时程序化生成

## 本地运行

```bash
npm install     # 仅需安装 ws（WebSocket）
npm start       # http://localhost:3099
```

- **单机闯关**：主菜单点"开始战斗（单机）"，无需连接
- **联机**：输入昵称后点"联机混战 / 联机合作"；把 `http://你的IP:3099` 发给朋友即可同场对战（同一局域网或公网服务器）
- 服务器接口：`/health`（在线状态）、`/api/leaderboard`（历史排行榜 JSON）

## 玩家载具

进场时可从三种车体中选择（与敌军同款外形，数值按玩家平衡）。战斗中与阵亡重生均不可换车，需返回大厅或重新进入后再选。

| 属性 | **猎手**（均衡） | **疾袭**（机动） | **重装**（重甲） |
| --- | --- | --- | --- |
| 装甲 | 120 | 80 | 200 |
| 前进移速 | 9.5 | 16.8 | 6.0 |
| 倒车移速 | 5.5 | 9.6 | 3.5 |
| 转向 | 2.3 | 3.8 | 1.5 |
| 炮塔转速 | 3.4 | 4.4 | 2.2 |
| 装填间隔 | 0.95 秒 | 0.72 秒 | 1.45 秒 |
| 直击伤害 | 30 | 22 | 48 |
| 弹速 | 60 | 68 | 48 |
| 溅射半径 | 3.4 | 2.6 | 4.6 |
| 溅射伤害 | 12 | 8 | 20 |

- **猎手**：攻防机动均衡，适合大多数战局
- **疾袭**：装甲最薄，移速 / 转向 / 装填最快，适合拉扯与绕后
- **重装**：装甲与单发伤害最高，走位慢、装填长，适合正面硬刚

穿甲弹补给期间伤害 ×1.5；过载引擎期间移速 +40%。
